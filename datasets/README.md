# Gurukul AI Datasets

This directory serves as the centralized data layer for the Gurukul AI platform.

## Structure
- `ncert_source/`: Original NCERT textbooks and teacher resources (unprocessed).
- `processed/`: Ingested and structured data ready for AI processing and application use.
- `database/`: Local database files and cloud exports.
- `assets/`: Media assets extracted or referenced by the curriculum.
- `logs/`: Data ingestion and processing logs.
- `manifests/`: Dataset versioning and metadata manifests.
- `scripts/`: Utility scripts for data migration and processing.
