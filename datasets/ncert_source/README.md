# NCERT Source Data

This directory contains unprocessed source material from NCERT.

## Structure
- `class_5/`: NCERT resources for Class 5.
- `class_6/`: NCERT resources for Class 6.

## Naming Convention
- Subject folders use lowercase (e.g., `mathematics`, `science`).
- Source files should retain original filenames if possible, or follow `[subject]_[type]_[version].pdf`.

## Ownership
- Managed by Content Acquisition Team.
