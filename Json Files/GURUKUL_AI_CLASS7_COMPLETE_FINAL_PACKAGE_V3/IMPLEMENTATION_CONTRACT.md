# Class 7 Fresh Content Contract

This package contains Class 7 educational content generated from the uploaded
NCERT textbook PDFs.

Coverage:
English 5 | Hindi 10 | Mathematics 15 | Science 12 | Social Science 20
Total 62 chapters.

42 components are supplied for every chapter.

Gemini is an IMPLEMENTATION ENGINE ONLY. It must not generate, replace,
paraphrase or invent educational content.

SOURCE_TEXT contains the extracted source text used for grounding.

Multimedia status:
VERIFIED_DIRECT_VIDEO = specific direct video verified
VERIFIED_OFFICIAL_PORTAL = official NCERT ePathshala resource portal
DISCOVERY_ONLY = YouTube search URL and NOT a verified direct video.

The original textbook ZIP is intentionally NOT embedded in this implementation
package to avoid upload-size failures. Keep the original uploaded textbook
archive separately as the source backup.

tests and clean production build.
