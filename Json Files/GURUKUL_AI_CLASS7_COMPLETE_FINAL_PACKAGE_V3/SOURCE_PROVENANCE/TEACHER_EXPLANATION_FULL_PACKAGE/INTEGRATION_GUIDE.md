# Integration Guide

1. Keep the original NCERT archives as source-of-truth backups.
2. Keep the enriched full package separate.
3. Add teacher_explanation as a new additive content layer.
4. Do not replace assessment_bank.json.
5. Do not replace lesson_content.json.
6. Resolve teacher explanations by exact class + subject + chapter_id.
7. Load only the active chapter.
8. Test one Class 5, one Class 6 and one Class 7 chapter.
9. Run validation before full rollout.
