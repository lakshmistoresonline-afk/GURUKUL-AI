# Gurukul Classes 5–7 — NCERT Chapter Questions

This package contains questions/exercises extracted from the exact NCERT chapter
PDFs supplied for Gurukul Classes 5, 6 and 7.

Because the source PDF itself is the chapter:
- Class/subject/chapter mapping is exact.
- No Kerala Board material is included.
- No AI-generated questions are included.
- No question from another chapter is assigned to this chapter.
- Existing Gurukul data is untouched.

This package is the NCERT textbook-question layer. Official CBSE assessment
questions can be added later only after the actual CBSE source files are
available/readable and each item passes the same chapter-content gate.
