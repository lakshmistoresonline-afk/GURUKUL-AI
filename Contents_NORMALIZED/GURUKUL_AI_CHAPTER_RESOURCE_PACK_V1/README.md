# GURUKUL AI — Chapter Resource Pack v1.0

Coverage: 183 curriculum chapters across Classes 5, 6 and 7.

Each chapter has:
- chapter UID / class / subject
- official NCERT portal
- official DIKSHA portal
- chapter-specific YouTube search URL
- chapter-specific web discovery URL
- directly verified YouTube videos where independently found

IMPORTANT:
- No fabricated YouTube IDs or URLs are included.
- A YouTube search URL is discovery metadata, NOT a verified video.
- Only the entries under `verified_videos` are direct video resources.
- Where the supplied inventory did not contain a trustworthy chapter title, the canonical chapter UID is retained rather than inventing a title.

Directly verified videos in this first pack: 2
Chapters with directly verified videos: 2

This pack is intended to be merged into the GURUKUL runtime resource layer after API/frontend mapping is implemented.
