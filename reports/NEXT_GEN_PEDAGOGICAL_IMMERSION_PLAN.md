## 2. Proposed Implementation Modules

### Module 1: Duolingo-Style Quest Path (Chapter Adventure Map)
- **Concept**: A winding, game-like adventure path on the home dashboard where chapter nodes unlock sequentially as students master quizzes and flashcards.
- **Experience**: Turns linear syllabus reading into an exciting, motivating quest.

### Module 2: Smart Spaced-Repetition Review Queue
- **Concept**: A dedicated practice mode that intelligently aggregates all flashcards marked for review or quiz questions answered incorrectly into a smart daily review deck.
- **Experience**: Reinforces long-term memory retention through targeted, low-friction practice.

### Module 3: Adaptive Typography & Dyslexia Support Profiles
- **Concept**: Additional reading comfort options (such as OpenDyslexic font family toggle and high-contrast color themes) in the reading comfort dropdown.
- **Experience**: Ensures universal accessibility and maximum reading comfort for every student.
