## 2. Proposed Implementation Modules

### Module 1: Interactive Knowledge Constellation Chapter Map
- **Concept**: A game-like visual node-link map on the dashboard connecting chapters as glowing star constellations.
- **Experience**: Students unlock chapters progressively, turning curriculum progress into an inspiring spatial journey.

### Module 2: Smart Spaced-Repetition Review Queue
- **Concept**: A dedicated study mode aggregating difficult flashcards and missed quiz questions into a smart daily review deck.
- **Experience**: Reinforces long-term memory retention through targeted, low-friction practice.

### Module 3: Micro-Achievement Toast Notifications
- **Concept**: Animated floating toast notifications with sound cues celebrating milestones (e.g., *"Chapter 1 Mastered!"*, *"Level Up: Active Explorer"*).
- **Experience**: Delivers immediate, joyful dopamine feedback for student persistence.
