## 1. Vision of the Fault-Free AI Orchestrator

To achieve absolute runtime intelligence without human intervention, the system requires a **Unified Neural-Symbolic Orchestrator** capable of:
1. **Zero-Configuration Autonomous Discovery**: Instantly indexing raw file trees (`Contents/`) via AST pattern matching.
2. **Probabilistic Schema Resolution**: Mapping unstructured or semi-structured JSON objects directly into normalized UI domain contracts.
3. **Self-Healing LLM Fallback**: Automatically generating missing explanations, marking schemes, and pedagogical hints when source data is sparse.
4. **Resilient Frontend UI Architecture**: Guaranteed zero unhandled runtime exceptions via React Error Boundaries and robust safe text renderers.
