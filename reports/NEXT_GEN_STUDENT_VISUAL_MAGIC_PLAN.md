- **Concept**: A dedicated review mode that automatically collects difficult flashcards and incorrect quiz items into a smart daily practice deck.

### Module 3: Dynamic Subject Atmosphere Themes
- **Concept**: Each subject environment features tailored ambient lighting and subtle iconography (e.g., geometric formulas for Mathematics, botanical motifs for Science, manuscript aesthetics for Literature).
